## Ejecutar archivos

### C++
```bash
# Solo ver resultado (no guarda binario)
g++ -std=c++17 archivo.cpp && ./a.out

# Guardar binario con nombre propio
g++ -std=c++17 -o salida archivo.cpp && ./salida

# Clang (alternativa)
clang++ -std=c++17 archivo.cpp && ./a.out
```

### Java
```bash
# Ejecutar directo (sin compilar)
java Archivo.java
```
