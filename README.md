## Ejecutar archivos

### C++
```bash
# Forma 1: Separado
g++ -std=c++17 -o salida archivo.cpp
./salida

# Forma 2: De un saque
g++ -std=c++17 -o salida archivo.cpp && ./salida

# Clang (alternativa)
clang++ -std=c++17 -o salida archivo.cpp && ./salida
```

### Java
```bash
# Ejecutar directo (sin compilar)
java Archivo.java
```
